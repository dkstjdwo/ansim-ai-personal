# 화면 설계서

기획서의 사용자 흐름을 바탕으로 화면 목록을 정리한 초안입니다. 화면별 구성과 와이어프레임은 확정 후 추가합니다.

| 화면 | 주요 내용 |
| --- | --- |
| 회원가입·로그인 | 계정 생성 및 로그인 |
| 메인 | 서비스 진입 및 면접 시작 |
| 이력서·지원 정보 | 이력서 등록, 기업·직무·모집공고 선택 |
| 면접 준비·진행 | 질문 확인, 음성 답변 및 다음 질문 |
| 면접 결과 | 점수와 AI 피드백 확인 |
| 마이페이지 | 사용자 정보와 과거 면접 기록 확인 |

- 사용자 흐름: [User Flow](../설계/UserFlow.md)
